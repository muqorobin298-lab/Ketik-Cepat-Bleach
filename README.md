# Ketik Cepat Bleach ⚔️

Tes kecepatan mengetik 30 detik bertema anime Bleach, dibuat pakai HTML, CSS, dan JavaScript.

🔗 **Main di sini:** https://muqorobin298-lab.github.io/Ketik-Cepat-Bleach/

## Fitur
- Ketik istilah Bleach dalam 30 detik
- Hitung kata per menit dan akurasi
- Latar anime makin panas seiring kata benar bertambah
- Rekor terbaik tersimpan di browser
